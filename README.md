# Store Site

فروشگاه ساخته‌شده با React، TypeScript و Vite.

## اجرا در محیط توسعه

```bash
npm install
npm run dev
```

آدرس پیش‌فرض Vite: `http://localhost:5173`

## ساخت نسخه نهایی

```bash
npm run build
```

خروجی قابل انتشار در پوشه `dist` ساخته می‌شود. برای مشاهده محلی خروجی:

```bash
npm run preview
```
